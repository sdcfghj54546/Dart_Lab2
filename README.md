## Ответы на вопросы

**1. В чём разница между полем класса и обычной переменной в функции?**
Поле класса принадлежит объекту и живет всё время, пока существует объект (доступно всем методам класса). Обычная переменная (локальная) существует только внутри своей функции и удаляется сразу после её завершения.

**2. Что такое конструктор и зачем он нужен?**
Конструктор — это специальный метод, который вызывается при создании объекта. Он нужен, чтобы сразу задать начальные значения полям (например, передать название и ID задачи при создании).

**3. Зачем нужен @override перед toString()? Что будет если его убрать?**
`@override` говорит компилятору, что мы намеренно переопределяем метод родительского класса. Если его убрать, программа продолжит работать, но ты потеряешь защиту от опечаток: компилятор не подскажет, если ты случайно ошибёшься в названии метода.

**4. Чем статическое поле static int \_counter отличается от обычного поля? Сколько копий этого поля существует в программе?**
Обычное поле есть у каждого объекта своё (свой ID). Статическое поле принадлежит самому классу. В программе существует **только одна копия** этого поля, независимо от количества созданных объектов — поэтому оно идеально подходит для счетчика.

**5. Что означает нижнее подчёркивание в \_counter?**
Оно делает переменную **приватной**. Это значит, что обратиться к ней и изменить её можно только внутри того же файла, где она объявлена. Из других файлов это сделать нельзя (защита от случайных изменений).
